# ML and Python Practice

Course practice code.

## Python fundamentals

Data types, sets, dictionaries, functions, classes, inheritance, encapsulation and polymorphism (`Datatypes.py`, `set.py`, `dictio.py`, `func.py`, `class.py`, `inheritance.py`, `encapsulation.py`, `polymorph.py`).

## Small apps

- `myapp.py` - Streamlit and Groq mini chatbot with voice input
- `RAG.py` - PDF question answering with FAISS and Groq (add your own `myfile.pdf`)
- `Sup.ipynb` - supervised learning notebook

API keys are read from the `GROQ_API_KEY` environment variable (see `.env.example`).
